# 架构与教学设计

## 三项创新如何实现

1. 知识结构可视化：`course.js` 中 30 单元映射成 5 章节 + 30 知识点 + 6 实验共 41 个节点。`knowledge.js` 明确编写先修关系。包含关系用实线，先修用虚线；目录视图提供相同的信息入口。
2. 理论实验交互化：每节包含目标、定义、关键原理、深入讲解、三步案例、代码说明、误区、问题和 D3 官方文档链接；九张对照表帮助区分容易混淆的概念。完整课程来源在独立参考资料页面展示。就地实验按知识内容选择。完整实验使用统一控制与反馈，不把视觉动画当作计算结果。
3. 学习过程反馈化：主动确认阅读、参数实验、双语挑战与解释组成证据。进度使用明确规则，不把浏览行为推断为理解程度。

## 数据与状态

- `src/data/course.js` 管理章节、基础教学内容与实验关联；`src/data/lessons/` 按章组织新增双语深入讲解与案例。`lessonDetails.js` 汇总细节、对照表和阅读来源，页面仅负责呈现。内容与参考章节的对应见 `docs/CONTENT_GUIDE.md`。
- `src/utils/data.js` 提供两套用途明确的确定性模拟数据。流水线处理记录数据；时序与螺旋共用 90 天数据。每个图形与表格由同一个计算结果驱动。
- `pipeline` 校验字段、分组、聚合与阈值；清洗排除缺失、无效或超出范围记录，保留合法 0。
- 时序范围使用 UTC 日期字符串的两端包含规则。日历与统计直接筛选原记录。选区折线对该子集聚合；浅色上下文折线展示全量分桶；改变粒度不会改变选区总量。
- 拟合将自变量限制在 [-1,1]，对多项式设计矩阵做列归一化与两次正交 QR 求解。训练与验证扰动不同。阶数最多 10，小于训练点数，并检测奇异性。
- 色彩亮度按 sRGB 线性化计算。色觉矩阵也在线性 RGB 中应用，再裁剪色域和重新编码。
- 语言是独立响应状态，只更新文本与图形标签，不重建组件或重置实验。正文、目标、错误说明、挑战与图谱均有等价资源。
- 学习状态存储键为 `visual-learning-lab-v1`；加载时校验版本及数组，捕获损坏数据和写入失败。

## 生命周期与性能

Vue 路由和六个复杂实验按需加载。D3 图形更新时清理旧图形和过渡；知识地图退出停止 Force Simulation、清理 Zoom；时序实验清理 Brush 与指针事件；CodeMirror 在退出销毁实例；所有预览定时器清理。减少动态偏好禁用 CSS 过渡并直接稳定图谱。

D3 Data-Join 演示保留 DOM 对象身份，以稳定 id 连接 Enter/Update/Exit。其他图表根据小型计算结果重绘，保留渲染逻辑简洁并避免重复事件。

## 编程沙箱边界

工作台从项目的 npm D3 包在构建时读取官方 bundle，随工作台按需加载，没有远程 CDN。用户代码仅在 `sandbox="allow-scripts"` 的 iframe 中执行，没有 `allow-same-origin`。主页面不调用用户代码。

CSP 默认禁止资源；只允许教学需要的内联脚本与求值、内联样式、data/blob 图像。网络 fetch、嵌套 iframe、Worker、object、表单被禁止。父页通信检查 `event.source` 和本次运行标识；标识由 `crypto.getRandomValues()` 的 16 个安全随机字节生成，兼容普通 HTTP 域名，不依赖仅安全上下文提供的 randomUUID。缺少安全随机数接口时显示双语错误并清空预览，不使用弱随机数替代。只接受固定状态与有限长度的纯文本错误。源代码通过 JSON 序列化和小于号转义嵌入，避免闭合 script 注入主文档。

该沙箱没有跨进程硬超时保证。恶意同步循环可能阻塞共享事件循环；5 秒看门狗只能在浏览器仍可调度时提示未响应。重建可恢复一般异常，但严重卡死需刷新/关闭页面。不应在此运行敌对代码。页面明确解释此限制。

## 可扩展位置

新增知识点：在 `course.js` 添加完整双语字段，在 `src/data/lessons/` 对应章节补充讲解、三步案例和代码说明，核对 `lessonDetails.js` 中对应章节的 D3 官方文档链接，并在 `knowledge.js` 添加真实先修关系。新增实验：提供组件、在 `labs` 配置登记、在 `Labs.vue` 懒加载映射，并更新章节关联实验权重及测试。新增挑战：更新 `quizzes.js`，同时调整每章题数计算（当前每章明确为两题）。
