# 课程作业演示脚本（约 7 分钟）

## 0:00–0:45 真实问题与首页

“传统课程的内容、示例和代码容易彼此分离。本作品的目标是让学习者理解知识关系、主动调节实验、验证自己的理解。它依据五章课程范围独立开发，没有使用老师网站源码。”

展示首页五章路径与真实进度；首次使用为零，不能用预设成绩制造学习效果。

## 0:45–1:45 创新一：知识结构可视化

打开知识地图，选择“比例尺”。说明实线包含与虚线先修，点击连接知识，搜索 Data-Join，拖动节点、缩放和平移。切换目录视图，说明触屏和键盘替代入口。沿节点进入章节。

“学习从线性列表变成可探索的网络，学生能看到为什么要先理解数据属性再选择视觉编码。”

## 1:45–3:15 创新二：理论实验交互化

在数据流水线先预测提高阈值后的变化，再把最低分从 0 调到 80。对照各阶段记录数与表格；改变分组与统计量，说明图表轴的语义如何改变。

打开图表对比的纠错场景：80 与 90 的柱图基线为 70，长度比例被放大为 2；调为 0 并开启标签，验证真实比例 1.125。

“每个控件都对应一个教学问题，数值计算和图形使用同一份结果。”

## 3:15–4:10 从概念到代码

工作台切换柱图示例，修改数组与 fill，再运行。故意输入错误，展示错误反馈与重置。解释 D3 被内置到无同源权限的 iframe，说明教学沙箱仍不能保证终止恶意无限循环。

## 4:10–5:10 进阶验证

时序实验选择 1 月 10–20 日，验证 11 天；切换周粒度，总量保持不变。拖动 Brush，看日历与摘要同步；聚焦日历格子展示详情。

若时间允许，拟合实验把阶数从 3 提到 9，比较训练与验证 RMSE，说明“更贴近训练点”不必然“更可信”。

## 5:10–6:20 创新三：学习过程反馈化

完成一次实验确认，到学习中心回答“基线 0 改为 70”的预测题。展示判断、解释与相关知识入口。返回知识地图形成闭环。

说明进度公式：阅读 50%、实验 25%、挑战 25%；热力格只代表已确认阅读，不伪造掌握度。刷新后进度保留，所有数据存储在本地浏览器。

## 6:20–7:00 双语、响应式与交付

在实验参数已修改时切换英文，展示正文、标签和解释同时切换，参数保留。缩小到手机宽度，展示导航折叠、纵向布局与日期输入。

“技术不是创新结论。真正的改进是把知识关系看清、把抽象理论拿来实验、把理解程度变得可检验。项目可独立构建并部署到 GitHub Pages 或 Nginx。”
