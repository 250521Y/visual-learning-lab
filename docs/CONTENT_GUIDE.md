## 关键概念边界

- 数据类型与测量尺度不同；数字编号仍可表示名义类别。
- 中文属性名在 JavaScript 中合法；统一命名是工程约定，不是语言限制。
- Data-Join 三态由身份匹配决定，不能仅比较新旧数组长度。
- tree.separation 调整邻近节点间隔，不是专用的父子距离参数。
- Lab 插值仍需检查目标显示色域；配色方案名称不是普遍无障碍保证。
- d3.line().curve 控制几何路径；统计拟合通过目标函数估计模型。basis 并不穿过所有控制点。
- 45° 倾角是设计启发，不能当作所有图表的正确性标准。
- 阿基米德螺旋转一圈的半径增量为 2πb；等弧长布点与固定天数对齐需要取舍。
- Catmull–Rom 的 alpha 是参数化指数，不等于一般意义上的张力参数。
- 时间先后不证明因果；连续时间也不意味着每一时刻都有观测。

这些边界用独立措辞解释，并参考 D3 API 文档核对实现语义。案例继续采用项目原有教学模拟学习记录，不将合成数据包装成真实人口或教学研究证据。
